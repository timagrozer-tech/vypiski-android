# Автоматические проверки «Выписок»

Ничего не собирают (ни APK, ни EXE). Берут последнюю версию страницы из архива проекта, создают синтетические
приказы (вымышленные ФИО) и проверяют программу в браузере Chromium без экрана.

```
python3 -m pip install playwright python-docx pillow && python3 -m playwright install chromium
tests/run_all.sh
```

| Файл | Что проверяет |
|---|---|
| `unit/register.test.cjs` | 45 случаев: ФИО в любом падеже → именительный, звания, виды событий, отпуска (вид, год, сутки, период), разбор приказа на пункты |
| `e2e/docx_equivalence.py` | разбор DOCX в фоновом потоке побайтно совпадает с DOMParser (таблицы, объединённые ячейки, правки, поля, рамки, повреждённые файлы) |
| `e2e/acceptance.py` | критерии DESIGN_SPEC 2.0: ZIP «приказы/год/месяц», Zip Slip, ZIP-бомба, дубликаты, PDF; SHA-256 приказа до/после выписки; в выписке только выбранные пункты; реестр с панелью просмотра; история выписок; Android-импорт ZIP через SAF (чтение частями) |
| `e2e/wizard_regression.py` | мастер выписки целиком до DOCX, подсказки «Чтобы продолжить…», ширина экрана, «Назад» |
| `e2e/background_import.py` | работа с программой во время импорта, «сбой» посередине и продолжение без дублей |
| `e2e/android_simulation.py` | путь приложения Android: папка через SAF, уведомления, продолжение, «Поделиться», размер текста |
| `e2e/dark_theme_scan.py` | на всех экранах тёмной темы нет светлых пятен и тёмного текста (телефон и Windows) |
