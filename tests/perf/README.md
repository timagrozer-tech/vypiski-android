# Нагрузочные и долгие проверки (12.77.11)

Эти скрипты не входят в `run_all.sh`: им нужен профиль браузера с большой базой (порт 8799 — один и тот же origin, иначе IndexedDB другая).

- `soak.py ASSETS PROFILE CYCLES RATE` — многочасовая прогонка: экраны, поиск, люди и события, мастер, массовое создание (каждый 4-й цикл с созданием ZIP), блокировка. После каждого цикла — сборка мусора и метрики (память, узлы DOM, обработчики). Ожидания через локаторы, без удержания ElementHandle (иначе DevTools сам держит узлы).
- `pure.py ASSETS PROFILE text|bulk|orderdoc|events` — тот же сценарий целиком внутри страницы (без объектов Playwright): чистое измерение утечек.
- `probe2.py ASSETS PROFILE '[js…]' REPS [SNAPSHOT]` — повтор последовательности экранов и снимок кучи.
- `heap2.py SNAPSHOT 'имя узла'…` — кратчайший путь удержания от корня до узла (кто держит отсоединённый DOM).
- `bkmem.py ASSETS PROFILE 0|1` — пик памяти при полной резервной копии.
- `inventory.js` — внедряется до страницы: считает MutationObserver, setInterval и обработчики window/document с местом создания.
