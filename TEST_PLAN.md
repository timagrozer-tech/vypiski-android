# План тестирования REVVL Camera Lab v0.3.8

Полный сеанс проверки на телефоне с A/B и списком того, что прислать: `DEVICE_TEST_PROTOCOL.md`.

## 1. Проверка запуска на REVVL 7 Pro 5G / Android 16

- [ ] Workflow **Verify sources (no APK)**: `compileDebugKotlin` и `testDebugUnitTest` успешны.
- [ ] Сборка `testDebugUnitTest` через GitHub Actions успешна.
- [ ] Сборка `assembleDebug` успешна; APK устанавливается без ошибок.
- [ ] Приложение запускается и запрашивает доступ к камере; без разрешения не падает.
- [ ] Отказ от доступа к микрофону не мешает фотографировать.
- [ ] Диагностика сообщает модель устройства и реальный список публичных Camera2 ID.

## 2. Основные режимы

- [ ] JPEG сохраняется и открывается из галереи.
- [ ] Переключение доступных объективов; возврат после ухода в фон.
- [ ] Сетка, EV, фокус касанием, зум и таймер 3/10 секунд.
- [ ] Форматы RAW+JPEG и Ultra HDR показываются только при поддержке выбранной камеры.
- [ ] OEM HDR/Night/Bokeh не активируются, если прошивка не объявляет их доступными.
- [ ] Видеозапись 1080p и, если есть, 4K; при отказе в доступе к микрофону нет краша.

## 2a. Проверки исправлений v0.3.1

- [ ] Автоповорот ВЫКЛ: снять фото и видео, держа телефон горизонтально — в галерее альбомная ориентация.
- [ ] Поворот телефона на 180° (перевёрнутый портрет/альбом) — ориентация снимка верна.
- [ ] Видео: начать запись, нажать «Домой» — ролик в галерее воспроизводится, статус «запись прервана, ролик сохранён».
- [ ] Видео: включить «ФОНАРЬ ON», сменить объектив и качество — фонарик остаётся включённым там, где есть вспышка.
- [ ] Фронтальная камера без вспышки: кнопка «ВСП. НЕТ» неактивна, снимок делается.
- [ ] Повернуть экран (автоповорот ВКЛ) в режиме ВИДЕО/HDR/СТЕК ×3 — режим и объектив сохраняются.
- [ ] Отказать в доступе к камере, затем нажать «СНЯТЬ» — запрос появляется снова; выдать разрешение в настройках и вернуться — превью запускается.
- [ ] Открыть PRO в режиме HDR и нажать «Отмена» — HDR остаётся включённым.

## 2c. Интерфейс v2 (0.3.4)

- [ ] Фото: рамка превью 3:4 совпадает с кадром снимка; видео: 16:9 совпадает с роликом.
- [ ] Спуск, миниатюра, объектив достаются большим пальцем одной руки; громкость делает снимок / старт-стоп видео.
- [ ] Миниатюра обновляется после фото, видео и СТЕК; для DNG — заглушка, без падения.
- [ ] Кнопка объектива: нажатие — следующий, удержание — список; при одном объективе — неактивна.

## 2d. PRO (0.3.5)

- [ ] Меню PRO на каждом объективе: недоступные пункты объясняют причину; сравнить с разделом PRO в диагностике.
- [ ] Ручная ISO/выдержка + пресет WB одновременно: оба действуют (раньше один набор затирал другой).
- [ ] Ручной фокус: объектив двигается при перемещении ползунка; «Отмена» возвращает прежнее; касание превью не сбивает фокус.
- [ ] Удержание пальца на превью: значок AE/AF 🔒; при наведении на яркое/тёмное экспозиция не меняется; касание снимает.
- [ ] Фиксация в видео: яркость ролика не «плавает» при панорамировании.
- [ ] Фиксация в СТЕК ×3: три кадра одинаковой яркости (в статусе нет отклонённых кадров при статичной сцене).
- [ ] Гистограмма: появляется в обычном JPEG, исчезает в RAW/Ultra HDR/OEM/СТЕК/видео; на ярком окне правый край красный; FPS превью не падает; нагрев за 5 минут не выше, чем без неё.
- [ ] Смена объектива или режима снимает фиксацию и ручные ISO/фокус; WB-пресет остаётся, если новый объектив его поддерживает.

## 3. «СТЕК ×3» — эксперименты

- [ ] Нажать «СТЕК ×3», убедиться, что RAW/Ultra HDR, ISO/выдержка, вспышка не доступны.
- [ ] Снять статичную сцену с хорошим освещением; дождаться прогресса 1/3, 2/3, 3/3.
- [ ] Результат JPEG появляется в `DCIM/REVVL Camera Lab`, корректно повёрнут, длинная сторона не больше 2304 px.
- [ ] Проверить статичную тёмную сцену и сравнить шум/детализацию со штатной камерой и одиночным JPEG.
- [ ] Проверить движущийся объект — не должно быть сильных призраков/шлейфов; возможна потеря качества.
- [ ] Прервать серию кнопкой «Домой»/свернуть: съёмка останавливается, в галерее нет недописанного файла.
- [ ] Проверить серию на фронтальной камере, оценить необходимость горизонтального зеркалирования.
- [ ] Повернуть телефон во время серии — серия завершается без ошибки размеров, ориентация по положению в начале серии.
- [ ] Повторить серию 5 раз, проверить отсутствие зависаний, невозможности переключить объектив и сильного нагрева.

## 3a. A/B для СТЕК ×3 v2 (0.3.3)

1. Включи СТЕК ×3, нажми кнопку **A/B: ВЫКЛ** → **A/B: ВКЛ**.
2. Штатив или упор; одна и та же сцена при трёх условиях: дневной свет, комната вечером, тёмная комната.
3. Для каждой сцены сравни на ПК в 100 % масштабе `REVVL_STACK_*.jpg` и `REVVL_STACK_*_REF.jpg`: шум в тенях, мелкие текстуры (ткань, листья), края.
4. Сцена с движением (человек машет рукой): нет ли двойных контуров у результата по сравнению с _REF.
5. С рук без упора: проверить, что результат не мягче _REF (совмещение).
6. Записать строку статуса после съёмки (кадры, «шум −N %», время) — это оценка, не измерение качества.
7. Отмена: нажать «Домой» во время «СОВМЕЩЕНИЕ И СОХРАНЕНИЕ» — нет файлов в галерее, нет зависания при возврате.

## 4. Диагностика при проблемах

1. Меню **ДИАГНОСТИКА → Скопировать** → передать текст отчёта.
2. Снять один неподвижный объект штатной камерой и REVVL Camera Lab (JPEG, потом «СТЕК ×3»); сравнить файлы в полном размере.
3. Если Actions показывает красный крест, прислать лог первого упавшего Gradle шага, а не только скриншот результата.
4. Если запускается, но объективы/функции не работают, прислать модель из «Настройки → О телефоне» и описание кнопки/ошибки.
