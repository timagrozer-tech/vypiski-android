## 2026-10-23 — Этап 5 (камера) завершён

**Сделано:**
- `core:database` v1: документы и страницы (Room). Файлы — отдельно от БД.
- `core:storage/DocumentRepository`: оригинал пишется атомарно под журналом, становится
  только для чтения, SHA-256 — в индексе; сбой → откат без остатков. Пересъёмка переносит оригинал
  в корзину (не удаляет). Импорт JPG/PNG/WEBP/HEIC/PDF: только `content://`, ≤ 200 МБ, формат по
  сигнатуре, затем проверка содержимого (размеры, ≤ 20 000 px; PDF — открывается, не зашифрован,
  ≤ 2000 страниц). Изображения — один документ, каждый PDF — отдельный.
- `PageImageLoader`: уменьшенное декодирование, поворот по EXIF, страницы PDF через PdfRenderer, LRU.
- Камера: превью, затвор (качество MAXIMIZE_QUALITY), вспышка выкл/авто/вкл/фонарик, фокус по
  касанию (через преобразователь видоискателя), 13 режимов (+ «Таблица», «Чертёж»), пакетная съёмка
  в один документ, «Переснять последнюю», «Готово» → просмотр. Номер документа сессии — в
  SavedStateHandle (переживает выгрузку процесса); каждый снимок сохраняется сразу.
- Живые данные: «Мои документы», «Недавние» на главной, «Импорт», просмотр документа.

**CI** 39966607986 — зелёный. По пути: нет Compose Foundation в `core:camera`; конфликт JVM-сигнатур
`setFlash`; в Robolectric `BitmapFactory` не сообщал размеры JPEG → запасной путь через заголовок/EXIF
(полезен и для части HEIC на устройствах). CI теперь выводит полный текст упавших тестов.

**Не проверено (нужен телефон):** реальная съёмка, вспышка, фокус, HEIC с конкретного устройства.

**Следующий шаг — этап 6:** обнаружение документа (OpenCV), подсветка границ, автосъёмка, правка углов.
