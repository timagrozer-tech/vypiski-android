# «Выписки» UI/UX 2.0 — отчёт по этапам (версия 12.75)

Основа: `DESIGN_SPEC.md`, `prototype.html`, `PROMPT_FOR_CLAUDE_OPUS_5_5.md` из пакета UI/UX 2.0.
**Сборки на этом этапе не выполнялись**: APK/AAB/EXE/установщики не создавались, сборочные GitHub Actions
переведены в ручной режим (`workflow_dispatch`), артефакт ранее запущенной сборки Windows удалён.

## A. Аудит
- Программа — одна офлайн-страница `app/src/main/assets/index.html` (около 30 модулей-«этапов», каждый следующий
  дополняет предыдущие), оболочки: Android (Kotlin + WebView, SAF, MediaStore, служба для фонового импорта) и
  Windows (Electron, `desktop/`). Общий интерфейс для двух платформ уже есть — это одна и та же страница.
- Данные: IndexedDB (приказы, выписки, индекс поиска, копии исходных файлов, журнал аудита). Сеть не используется.
- Риски: наслоение стилей разных этапов (решено последним слоем темы), большой объём одной страницы (решено
  разбором в фоновых потоках и ленивой отрисовкой), отсутствие реальных образцов приказов для настройки разбора.

## B. Архитектура
Ничего не переписывалось «с нуля»: новые экраны — отдельный модуль `stage12-75-ui2`, использующий существующие
репозитории, парсер, мастер выписок, проверку целостности и журнал аудита. Прежний вид реестра «папками» сохранён.

## C–D. Дизайн-токены, компоненты, 7 экранов на реальных данных
| Экран | Где | На реальных данных |
|---|---|---|
| Главная | счётчики, действия, последние приказы, предупреждения | да |
| Реестр приказов | поиск, сортировка, фильтр событий, статусы, список/папки, панель просмотра (Windows) | да |
| Поиск | полнотекстовый поиск по индексу: ФИО в падежах, инициалы, фраза, номер, период, контекст совпадений | да |
| Импорт | папка, файлы, ZIP; структура год/месяц; очередь, прогресс, ошибки, дубликаты; фон | да |

Плюс «Таблица приказов» с выгрузкой в Excel. Темы: светлая/тёмная/как в системе. Фокус — янтарное кольцо 3 px.

## E. Импорт папок и архивов
Рекурсивно: папка целиком (Android — Storage Access Framework без копирования; Windows/браузер — выбор папки или
перетаскивание), ZIP с любой вложенностью и русскими именами (CP866/UTF-8), чтение ZIP частями. Защита: Zip Slip
(`..`), ZIP-бомбы (размер > 60 МБ или сжатие > 250:1 отсеиваются ещё при анализе), CRC32, вложенные архивы и
RAR/7Z/PDF — только сообщение в журнале, дубликаты по SHA-256 файла и текста.

## F. Выписка без изменения приказа
Выписка — новый DOCX со своим ID, датой, источником, версией и SHA-256. Перед формированием и после него
пересчитываются SHA-256 сохранённой копии исходного файла и текста приказа; результат на экране и в журнале аудита.
Изменение текста приказа запрещено на уровне хранилища (неизменяемые поля).

## G. Что реально протестировано (headless Chromium, синтетические приказы)
`tests/run_all.sh`: 45 unit-проверок разбора ФИО/событий; эквивалентность разбора DOCX (325 документов);
24 проверки приёмки DESIGN_SPEC (ZIP «приказы/год/месяц» с Zip Slip/бомбой/дублем/PDF; Android-путь ZIP через SAF
с чтением частями; SHA-256 до/после; содержимое выписки; реестр; история); мастер выписки до DOCX; фоновый импорт со
«сбоем» и продолжением без дублей; имитация Android-оболочки; тёмная тема на телефоне и Windows без дефектов.
Дополнительно вручную в ходе работы: запуск настоящего Electron 37 (Linux) — страница с `app://`, сеть закрыта,
сохранение в «Загрузки\Выписки», ни одного исходящего соединения; открытие `index.html` напрямую из папки в Chromium.
Kotlin-код проверен компилятором Kotlin 2.0.21 против `android.jar` API 35 (androidx — сигнатурные заглушки).

## Не проверено / осталось
- На настоящем телефоне Android и на настоящем компьютере с Windows программа этой версии не запускалась (сборки
  запрещены этим этапом). Сборка Gradle целиком (с androidx) выполняется только в CI.
- Образец настоящей выписки и обезличенные настоящие приказы не предоставлены: разбор ФИО и событий проверен на
  синтетических текстах; на реальных формулировках возможны пометки «проверить» — для настройки нужны образцы.
- PDF — через системную печать (Android: служба печати; Windows: «Microsoft Print to PDF»); отдельного генератора PDF
  нет. Основной формат — DOCX.
- Фильтр «событие» есть в реестре и таблице; в полнотекстовом поиске событие задаётся словами запроса.
- Windows-сборка не подписана сертификатом (SmartScreen предупредит при первом запуске).
