# Аудит «Выписки» 12.76 по единому ТЗ v7.1 + Excel Pro

Дата аудита: 21.10.2026. Объект — реальный код ветки `dev`:
`app/src/main/assets/index.html` (весь интерфейс, ~48 блоков `<script id="stage…">`), Android-оболочка
`app/src/main/java/**` (MainActivity, NativeBridge, ImportService), Windows-оболочка `desktop/` (Electron).
Сборки (APK/AAB/EXE/установщики) не выполнялись и не выполняются — по требованию заказчика.

Обозначения статуса «до»: **есть** — найдено в коде и проверено тестом; **частично** — часть требования
есть; **нет** — в коде отсутствует. Столбец «Этап» — где закрывается пробел (см. план ниже).
Итоговый статус «после» — в `docs/REPORT_V7_1.md`.

## 3. Риски, найденные при аудите
1. **Нет авторизации** (P0): любой, кто открыл приложение, видит приказы и ФИО.
2. **Открытая резервная копия JSON** (P0): содержит тексты приказов без шифрования.
3. Данные IndexedDB не шифруются приложением; защита на устройстве — шифрование ОС (Android FBE, BitLocker). Экран входа — это контроль доступа в интерфейсе, а не шифрование. Отражено в ADR-2.
4. Проверки прав выполняются в том же процессе, что и интерфейс: человек с доступом к DevTools/отладке может их обойти. В Windows-версии DevTools отключены в production-режиме; на Android WebView-отладка выключена в release.
5. OCR и PDF не поддерживаются — сканы не распознаются (сообщается при импорте).
6. Совместная работа нескольких ПК — только чтение общих источников по SMB, общей базы нет.

## 4. ADR
- **ADR-1. Оставить однофайловую архитектуру.** Новые функции — новые блоки `stage12-77-*`, старые API не меняются. Переписывание не требуется и опасно для данных.
- **ADR-2. Авторизация и шифрование.** Пароли — PBKDF2-SHA-256 310 000 итераций (WebCrypto есть во всех целевых WebView/Chromium; Argon2id потребовал бы сторонней WASM-библиотеки без аудита в проекте). Резервные копии — AES-256-GCM, ключ из отдельной фразы восстановления (PBKDF2 600 000, соль 16 байт, nonce 12 байт), формат версионируется. Пароль входа не используется как ключ копии. Данные в IndexedDB не шифруются — документировано.
- **ADR-3. Несколько рабочих мест.** У каждого ПК свой индекс; SMB-папки — только источники для чтения; общий файл базы по SMB не используется. Согласование через сеть не реализуется; перенос — зашифрованным пакетом.
- **ADR-4. Живые папки.** Только Windows-версия (Electron main-процесс: `fs.watch` + сверка по расписанию). Обычная веб-страница и Android-WebView без фоновой службы этого не умеют — не обещаем.
- **ADR-5. Excel-импорт.** Только чтение значений; формулы не вычисляются; книги с макросами читаются без исполнения (`vbaProject.bin` игнорируется), внешние ссылки не открываются. XLS (BIFF) не поддерживается без проверенной библиотеки.
