# Установка «291 Сканер» на телефон

Требования: Android 10 или новее.

1. Скачайте APK из артефактов сборки GitHub Actions (`scanner291-debug-apk` или
   `scanner291-release-apk`). Подойдёт файл `app-universal-*.apk` — он работает на любом
   телефоне. Файлы `app-arm64-v8a-*.apk` меньше и подходят для большинства современных
   телефонов.
2. Сверьте контрольную сумму с `SHA256SUMS.txt` из того же артефакта
   (на компьютере: `sha256sum файл.apk`).
3. Перенесите APK на телефон (кабель, карта памяти) и откройте его в «Файлах».
4. Разрешите установку из этого источника, когда Android попросит
   (Настройки → Приложения → Специальный доступ → Установка неизвестных приложений).
5. После установки это разрешение можно отключить обратно.

Проверка офлайн-режима: «Настройки → Приложения → 291 Сканер → Разрешения» — в списке нет
доступа к сети; приложение работает в режиме полёта.

Debug- и Release-версии ставятся рядом (у Debug суффикс `.debug`), данные у них раздельные.
