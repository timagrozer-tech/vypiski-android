# План реализации (ТЗ v3.0, 23 этапа) с проверяемыми критериями

Статус этапа меняется только по факту проверки — см. `docs/STATUS.md`.
Каждый этап: коммит(ы) в ветку `scanner291` → зелёный CI → запись в `docs/PROGRESS.md`.

| № | Этап | Критерий готовности (как проверить) |
|---|---|---|
| 1 | Аудит требований и репозиториев | `docs/AUDIT.md`: 9 репозиториев с лицензией, датой, решением; разница v1.3→v3.0; ADR-0013…0017 |
| 2 | Архитектура и Gradle | Модули `core:*` (15) и `feature:*` (9) + `build-logic`; связка версий ADR-0013; Hilt; нет циклов (`./gradlew :app:dependencies` + проверка графа); CI зелёный; `zipalign -c -P 16` проходит для всех `.so` |
| 3 | Дизайн-система | Токены = палитры ТЗ (unit-тест сверяет hex); компоненты: кнопки (4 состояния), карточки, стекло с фолбэком без blur на API < 31, переключатель «Назвать файл по ФИО»; скриншот-тесты Roborazzi светлой/тёмной темы |
| 4 | Все основные экраны | 13 маршрутов навигации; Compose UI-тест открывает каждый; холодный старт сразу на «Главную» без удержания SplashScreen; нет кнопок без действия (UI-тест: у каждой видимой кнопки есть обработчик, ведущий к реальному действию) |
| 5 | Камера | CameraX: превью, снимок, вспышка, фокус по тапу, пакетная съёмка, пересъёмка; оригинал пишется через `OriginalStore` и не меняется (инструментальный тест: SHA-256 до/после); импорт JPG/PNG/WEBP/HEIC*/PDF |
| 6 | Обнаружение документа | OpenCV-детектор; IoU с разметкой ≥ 0,9 на ≥ 90 % `testdata/scans`; автоснимок по `AutoCapture`; ручная правка углов с лупой |
| 7 | Базовая обработка | Перспектива, поворот, тени, шум, контраст по рецепту; рецепт обратим (повторный рендер из оригинала побитно совпадает) |
| 8 | Hybrid HD Pro | Маски текст/печать/подпись/фон, 3 профиля, 10 параметров; тест: доля сохранённых пикселей эталонных масок печати и подписи ≥ 0,95; нет генеративных операций (только детерминированные фильтры) |
| 9 | Библиотека фильтров | ≥ 30 пресетов, 18 ручных параметров, пользовательские пресеты; тест различимости: любые два пресета дают средн. разницу ≥ порога хотя бы на одном эталоне; воспроизводимость (один вход → один выход) |
| 10 | OCR | Tesseract rus+eng, страница и пакет, текстовый слой, правка, FTS-поиск; CER/WER и время на `testdata/ocr` для «Быстрого» и «Высокой точности» → `reports/ocr-metrics.md`; OCR-текст не попадает в logcat (тест) |
| 11 | Document Intelligence и ФИО | ФИО (готово) + тип, дата, номер, заголовок, организация; шаблоны приказа/рапорта; всё требует подтверждения; ≥ 40 JVM-тестов на реальных обезличенных фразах |
| 12 | PDF Engine | Создание, просмотр, объединение, разделение, перестановка, поворот, извлечение, добавление, сжатие, OCR-слой, аннотации, графическая подпись, печать; тест: число страниц и текст сохраняются, кириллица извлекается; разбор чужих PDF по ADR-0017 |
| 13 | Водяной знак | Рендер «В/ч 65384» в PDF/JPG/PNG по `WatermarkPlanner`; инструментальный тест: знак слева внизу, повёрнут на 90° против часовой, 20 %, не перекрывает чернила; повторный экспорт не удваивает |
| 14 | Менеджер документов | Room: папки, теги, избранное, корзина, дубликаты, умные коллекции как запросы (без копий файлов); тесты DAO |
| 15 | Smart Batch Engine | Единый менеджер задач: ID, состояние, прогресс, отмена, повтор, промежуточное состояние; тест: ошибка в 1 из 30 документов не теряет остальные 29; ограничение параллелизма OCR |
| 16 | Quality Gate | Резкость, освещённость, блики, полнота границ, наклон, видимость текста, обрезание, фон — с порогами в коде и тестами на эталонах; три вердикта; сохранение не блокируется |
| 17 | Smart Export | PDF, PDF+OCR, JPG, PNG, TXT; DOCX/XLSX — только с измеренным качеством; 6 режимов; оценка размера (погрешность измерена); проверка результата перед «успешно» |
| 18 | Document Health Center | Находит повреждённые файлы, нет миниатюр, незавершённые операции, потерянные ссылки, дубликаты, нет OCR-индекса; исправления только с подтверждением; пересоздание индекса не трогает оригиналы (тест) |
| 19 | Безопасность | Keystore AES-256-GCM, хранилище, биометрия, проверка URI и импорта, лимиты, бэкап исключён, нет экспортируемых компонентов кроме launcher (тест по манифесту) |
| 20 | Оптимизация | Adaptive Performance (память, ядра, `PowerManager` thermal), тайлы, LRU миниатюр; модуль `:baselineprofile` и Baseline Profile; Macrobenchmark холодного старта и открытия камеры (числа — только измеренные) |
| 21 | Автотесты | Все критические проверки ТЗ ч. XXI автоматизированы и зелёные в CI, включая авиарежим и убийство процесса |
| 22 | Сборка APK | Подписанный Release в CI, размер и SHA-256 в сводке, `apksigner verify` |
| 23 | Финальная проверка | `docs/QA_CHECKLIST.md` пройден на реальном телефоне пользователем; критерии ч. XXIV подтверждены |
