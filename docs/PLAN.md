# План реализации с проверяемыми критериями

Статусы: ✅ сделано и проверено · 🟡 код написан, проверяется только в CI/на устройстве · ⬜ не начато.
Статус меняется только по факту выполненной проверки (см. `docs/STATUS.md`).

| № | Этап | Критерий готовности (как проверить) |
|---|---|---|
| 1 | Архитектура, ADR, структура | Документы в `docs/`; `settings.gradle.kts` содержит все модули; CI-задача `projects` выполняется |
| 2 | Дизайн и навигация | Тема из токенов, 12 экранов в навигации; Compose UI-тест проходит по всем маршрутам |
| 3 | Камера и сканирование | Инструментальный тест: съёмка на эмуляторе с виртуальной сценой; ручной чек-лист на устройстве: автообнаружение, автозатвор, вспышка, фокус, пакет |
| 4 | Обработка изображений | Тесты на `testdata/scans/*`: IoU найденного четырёхугольника с разметкой ≥ 0,9 на ≥ 90 % образцов; фильтры не стирают тонкие штрихи (доля сохранённых пикселей эталонной маски подписи ≥ 0,95) |
| 5 | PDF Engine | Тест: создать 3 страницы → объединить → разделить → повернуть → проверить число страниц, текстовый слой извлекается PdfBox, кириллица совпадает |
| 6 | Файловый менеджер | Тесты Room: CRUD, FTS-поиск по OCR, корзина и восстановление, дубликаты по хешу |
| 7 | Офлайн-OCR | CER/WER на `testdata/ocr/` (реальные сканы + эталон), отчёт в `reports/ocr-metrics.md`; без сети |
| 8 | Определение ФИО | Unit-тесты `FioExtractorTest`: ≥ 25 сценариев (падежи, КАПС, инициалы, двойные фамилии, несколько лиц, отсутствие отчества, низкая уверенность) |
| 9 | Галочка «Назвать файл по ФИО» | Состояние в DataStore; UI-тест: вкл → имя по ФИО, выкл → имя по дате; сохранение не блокируется |
| 10 | Пакетная обработка по ФИО | Unit-тесты `BatchNamingPlannerTest`: уникальность в пакете и среди существующих, флаги неоднозначности, массовая правка |
| 11 | Водяной знак «В/ч 65384» | Unit-тесты `WatermarkPlannerTest`; инструментальный: экспорт PDF/JPG/PNG, знак слева внизу, повёрнут на 90° против часовой, не перекрывает чернила, повторный экспорт не удваивает |
| 12 | Редактор | Unit-тесты рецепта (undo/redo, обратимость); закрашивание удаляет слова из текстового слоя |
| 13 | Безопасность | Тест: в `PackageInfo.requestedPermissions` нет INTERNET; шифрование/расшифровка Keystore; отклонение `file://` и чужих URI |
| 14 | Оптимизация | Baseline Profile, макробенчмарк холодного старта и открытия камеры; пиковая память при экспорте 50 страниц < 256 МБ |
| 15 | Тестирование | Все тесты CI зелёные; ручной чек-лист `docs/QA_CHECKLIST.md` пройден на устройстве |
| 16 | Финальная сборка | Подписанный release APK собран в CI, установлен на реальный смартфон, пункты раздела 20 ТЗ подтверждены |
