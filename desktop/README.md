# Выписки для Windows 10/11

Настольная версия той же программы, что и приложение для Android: страница `app/index.html` (берётся при сборке
из последнего архива проекта `Vypiski-Android-Stage-*.zip`) открывается во встроенном Chromium (Electron).

## Что умеет настольная версия
- Всё, что и телефон: загрузка приказов (папка целиком, файлы, ZIP, перетаскивание в окно), поиск, мастер выписок,
  таблица приказов с выгрузкой в Excel, шаблоны, резервные копии, светлая и тёмная тема.
- Боковое меню разделов на широком экране; масштаб — Ctrl+колесо мыши или меню «Вид».
- Сохранённые файлы попадают в «Загрузки\Выписки» (папку можно сменить в «Настройках»), после сохранения —
  кнопка «Показать в папке».
- Во время длинной загрузки компьютер не уходит в сон, ход виден на кнопке программы в панели задач, по окончании —
  уведомление Windows.
- Печать и PDF — стандартное окно печати Windows (принтер «Microsoft Print to PDF»).

## Безопасность и данные
- Программа не выходит в интернет: все сетевые запросы запрещены, фоновые подключения движка отключены.
- Данные хранятся в профиле пользователя: `%APPDATA%\Vypiski`. Установленная и переносная (portable) версии
  используют одну и ту же базу. При удалении программы данные не удаляются.
- Файлы программы не подписаны сертификатом, поэтому при первом запуске Windows SmartScreen может показать
  «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

## Сборка
GitHub Actions (`.github/workflows/build-desktop.yml`, Windows): Node 20, Electron 37, electron-builder.
Результат — `Vypiski-Setup-<версия>.exe` (установщик) и `Vypiski-Portable-<версия>.exe` (без установки).
Локально: `npm install`, затем `npm start` (запуск) или `npm run dist` (сборка на Windows).
