# Лаборатория детектора документа

Инструмент разработки, **в приложение не входит**. Повторяет `core/imageprocessing/.../DocumentDetector.kt`
на Python (OpenCV), чтобы настраивать алгоритм за секунды, а не через сборку и эмулятор.

- `synthetic.py` — генератор синтетических документов с известными углами (те же типы, что в
  `DetectorAccuracyTest`: низкий контраст, пёстрый фон, тень, размытие, обычный) и базовый детектор.
- `detector.py` — текущий алгоритм (с «опорой на границы»).

```bash
pip install opencv-python-headless numpy
python3 detector.py
```

Замер 2026-10-23 (OpenCV 5.0 Python): 360 документов, IoU ≥ 0.9 — 359 (99,7 %), средний IoU 0,98,
~12 мс на кадр 480 px; без «опоры на границы» — 93–96 % (пёстрый фон 77–83 %).
Ложных срабатываний на 100 кадрах без документа — 0.

Синтетика не заменяет реальные фото: набор снимков пользователя (`testdata/scans`) — отдельная задача.
