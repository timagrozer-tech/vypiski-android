# Лаборатория обработки (этап 7)

Копия `PageRenderer` (core:imageprocessing) на Python + генератор синтетических страниц с известным
эталоном. Нужна, чтобы подбирать алгоритмы за секунды, а не через сборку и эмулятор.

```
python3 lab.py base      # сравнение способов убрать тени
python3 lab.py filters   # фильтры, бинаризация, шумоподавление
python3 lab.py aspect    # ошибка пропорций листа без известного формата
python3 lab.py final     # итоговые параметры + проверка побитной повторяемости
```

Набор: 30 страниц A4 (текст, таблица, печать), лист в перспективе на столе, 5 типов освещения
(ровное, градиент, мягкая тень, резкая тень, тусклое), оттенок бумаги, шум σ=4, JPEG 88.
Углы листа берутся точные — так измеряется именно улучшение, а не поиск углов (он измерен на этапе 6).

Метрики (на эталонной сетке, без полей 3 %): фон — среднее ± разброс яркости на чистой бумаге
и 1-й процентиль (тёмные пятна тени); текст — средняя яркость «чернил»; F1 — совпадение
пикселей текста при пороге 128 с эталоном; фон-ош — доля фона, ставшая «текстом».

## Результаты (Python 3, OpenCV 5.0.0, 2026-10-23)

Выбор способа убрать тени (фильтр «Серый»):

| Вариант | Фон | p1 (худший) | F1 (худший) | Фон-ош |
|---|---|---|---|---|
| Без удаления теней | 212.9 ± 26.9 | 86 | 0.782 (0.292) | 10.40 % |
| dilate + median | 250.6 ± 2.5 | 225 | 0.886 (0.875) | 0 % |
| **close + gauss (выбран)** | 251.9 ± 2.2 | 233 | 0.884 (0.875) | 0 % |
| dilate + gauss | 250.6 ± 2.6 | 219 | 0.886 (0.875) | 0 % |

Шумоподавление: медиана 3×3 «съедает» тонкие штрихи (F1 0.884), гаусс 3×3 — лучший F1 (0.897) при той же
скорости; билатеральный фильтр чуть лучше по фону, но заметно медленнее на 12 Мп — выбран гаусс.
Бинаризация: адаптивный порог C=12 — F1 0.946 без ложного фона; Оцу 0.935, фиксированный 0.937.
«Усиленный текст»: гамма 1.8 (1.3 → F1 0.927, 1.6 → 0.947, 2.0 → 0.964 при более тёмных пятнах фона).

Повторный рендер того же рецепта побитно совпадает (в приложении это проверяет `PageRendererTest`).

Пропорции листа по углам без известного формата: ошибка в среднем 2.9 %, максимум 8.9 % (перспектива
искажает длины сторон). Поэтому при известном формате режима (A4, A5, паспорт…) и пропорциях углов
в пределах 15 % от формата используется точное соотношение сторон формата.

Ограничения: страницы синтетические (шрифты Hershey, латиница); на реальных снимках цифры будут
другими — их измеряем на этапе 21 (набор реальных документов).
