# Лаборатория обработки (этап 7)

Копия `PageRenderer` (core:imageprocessing) на Python + генератор синтетических страниц с известным
эталоном. Нужна, чтобы подбирать алгоритмы за секунды, а не через сборку и эмулятор.

```
python3 lab.py base      # сравнение способов убрать тени
python3 lab.py filters   # фильтры, бинаризация, шумоподавление
python3 lab.py aspect    # ошибка пропорций листа без известного формата
python3 lab.py final     # итоговые параметры + проверка побитной повторяемости
```

Набор: 30 страниц A4 (текст, таблица, печать), лист в перспективе на столе, 5 типов освещения
(ровное, градиент, мягкая тень, резкая тень, тусклое), оттенок бумаги, шум σ=4, JPEG 88.
Углы листа берутся точные — так измеряется именно улучшение, а не поиск углов (он измерен на этапе 6).

Метрики (на эталонной сетке, без полей 3 %): фон — среднее ± разброс яркости на чистой бумаге
и 1-й процентиль (тёмные пятна тени); текст — средняя яркость «чернил»; F1 — совпадение
пикселей текста при пороге 128 с эталоном; фон-ош — доля фона, ставшая «текстом».

## Hybrid HD Pro (этап 8)

`hybrid.py` — копия `PageRenderer.hybrid` (Kotlin). Маски: цветные чернила (насыщенность ≥ 60 и
яркость ≤ 235, раскрытие 2×2, расширение на 1–2 px) и текст (адаптивный порог, без цветных чернил).
Сборка: текст — кривая/резкость (или чёрно-белый с мягким краем), фон светлее порога — белый,
цветные чернила — исходный цвет с усилением насыщенности. Генеративных операций нет.

Набор: те же 30 страниц + синяя круглая печать поверх текста и синяя подпись (эталонные маски).
«Сохранено» — доля пикселей эталонной маски, различимых как синие чернила на входе (после перспективы и
выравнивания света), которые остались синими чернилами на выходе (`python3 lab_hybrid.py`):

| Режим | Печать (худший) | Подпись (худший) | Фон | F1 текста |
|---|---|---|---|---|
| Усиленный текст | 0.000 | 0.000 | 248.9 ± 4.4 | 0.979 |
| Чёрно-белый | 0.000 | 0.000 | 255.0 ± 0.3 | 0.961 |
| Цветной | 1.000 (0.995) | 0.999 (0.994) | 251.5 ± 2.3 | 0.900 |
| **Hybrid «Документ»** | 0.999 (0.990) | 0.999 (0.986) | 255.0 ± 0.2 | 0.971 |

Перебор насыщенности 40/50/60, яркости 235/245, расширения 2/3 на сохранение печати не влияет;
насыщенность 60 даёт лучший F1 текста (меньше серого текста попадает в «цветное»).
Ограничение: проверены синие чернила; красные печати выделяются той же маской (по насыщенности),
но отдельно не измерены — этап 21.

## Библиотека фильтров (этап 9)

36 пресетов = базовый фильтр (+ профиль Hybrid) + 16 ручных параметров (`Adjustments`, чистый Kotlin,
проверяется JVM-тестом `PresetsTest`). Различимость (порог — средняя разница ≥ 2 уровней хотя бы на одном эталоне):

- пресеты с общей основой — `PresetsTest` на 3 эталонах (документ, цветное фото, синие чернила): минимальная пара 7.33;
- основы между собой — `python3 lab_bases.py` на 4 страницах с печатью и подписью + цветном эталоне
  с «предметами»: все 55 пар различимы, минимальная 3.83 (Hybrid «Документ» / «Контраст»).
  Первый замер выявил «Чек» ≈ «Чёрно-белый» (1.16): «Чек» получил утолщение штрихов — стал и различимым,
  и точнее на бледном тексте (F1 0.994).

## «Документ» v2 — вид «чистого электронного документа» (2026-10-24)

`python3 lab_doc.py all img` — 12 страниц с реальными шрифтами (DejaVu, кириллица), синей печатью и подписью,
перспективой, тенью, **сгибами листа (вчетверо) и зерном бумаги**. Фон — по чистым местам эталона; «разброс
клеток» — ст. отклонение средней яркости фона по клеткам 8×8; p1 — самые тёмные 1 % фона (сгибы, тени);
CER — tesseract 5.3.4, модели из APK (tessdata_fast rus+eng), без предобработки внутри Tesseract.

Изменение v2: после деления на фон — «уровни сканера»: чёрная точка = 0.5-й процентиль (текст), белая =
0.88·255 (фон), гамма 1.4, нерезкая маска 0.6; цветные чернила (печать, подпись) — по маске HSV, в своём цвете.
Перебор белой точки 0.80/0.84/0.88 и гаммы 1.2/1.5 давал CER 2.2–2.5 % — выбрано 0.88 (меньше риск потерять
бледный текст). «Ч/Б» получил те же уровни до бинаризации: CER 8.66 % → 3.99 %, сгибы больше не чернеют.
Известное ограничение: очень резкий сгиб может остаться тонкой светло-серой линией.

Ориентация (`lab_orient.py`): профили проекций (строки горизонтальны или вертикальны) + уверенность Tesseract
для 0°/180° — **48/48** (12 страниц × 4 поворота), ~1.8 с на страницу через CLI на x86 (на телефоне — иначе).
Время на телефоне не измерено мной: экран «Обработка» показывает время рендера превью, экспорт — секунды на страницу.
